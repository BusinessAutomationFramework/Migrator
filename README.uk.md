# Migrator

Схемо-орієнтований рушій переносу даних між базами 1С:Підприємство / BAF.

Migrator переносить довідники та документи між двома базами 1С (наприклад,
серверною джерельною та файловою приймальною), зберігаючи внутрішні UUID,
використовуючи:

- **BridgeTool** (`BridgeTool/`) — локальна зовнішня обробка, яка виконує
  загальні примітиви читання/запису лише проти бази-ПРИЙМАЧА. Вона ніколи
  не встановлює зовнішніх з'єднань.
- **COM** — використовується лише Python-оркестратором для читання з бази-
  ДЖЕРЕЛА (через 32-бітний PowerShell-скрипт), ніколи самим BridgeTool.

## Використання

    python -m migrator run <корінь>:<завдання> [--limit N]  # виконати перенос
    python -m migrator suggest <корінь>:<завдання>          # запропонувати related_catalogs
    python -m migrator gui                                   # локальна веб-панель

Завдання - це файли `schema.yaml` під зареєстрованим коренем завдань
(див. `migrator.config.example.yaml`).

## Стан

v1.0.0 - завершено: схемо-орієнтований рушій (схеми джерела/приймача,
мапінг полів, каскадування пов'язаних довідників, хуки пайплайна, табличні
частини), локальний GUI (дашборд, редактор схем, монітор, налаштування),
двомовна документація, і придатні для повторного використання скіли Claude
Code, засновані на здобутому досвіді. Acceptance-тест (повний, без
обмежень, перенос "Склади" з каскадуванням у 8 пов'язаних довідників)
підтверджено - детальні результати в `CHANGELOG.md`.
